# Wongnok Recipes

เว็บแอปพลิเคชันสำหรับแชร์สูตรอาหารและเมนูอาหารหลากหลาย โดยผู้ใช้สามารถลงทะเบียน, สร้างเมนู, แก้ไขเมนู, ลบเมนู และให้คะแนนเมนูได้



## ลิงก์ใช้งาน

- **เว็บไซต์จริง (Deployed):**  
  https://505985-wongnok-recipes.netlify.app/

- **GitHub Repository:**  
  https://github.com/gungfuu1/505985-wongnok-recipes



## เทคโนโลยีที่ใช้

- HTML, CSS (Responsive Design)
- JavaScript (Axios สำหรับ REST API)
- Supabase (Backend, REST API, Database)
- Netlify (Hosting)



## ขั้นตอนการรันเว็บแอป (สำหรับนักพัฒนา)

1. **Clone โปรเจกต์จาก GitHub**

   ```bash
   git clone https://github.com/gungfuu1/505985-wongnok-recipes.git
   cd 505985-wongnok-recipes

2. เปิดไฟล์ index.html ในเบราว์เซอร์
เนื่องจากเป็นเว็บแบบ Static จึงสามารถเปิดผ่านเบราว์เซอร์โดยตรง ไม่งั้นก็ใช้ Live Server ใน VSCode เพื่อความสะดวก

3. ตรวจสอบไฟล์ script-non-module.js
ไฟล์นี้จะเชื่อมต่อกับ Supabase API สำหรับการดึงข้อมูล, การล็อกอิน, และการลงทะเบียน (CRUD)

4. ตั้งค่า Supabase (ใช้ API ของตัวเอง)
เข้าไปแก้ไข URL และ API Key ในไฟล์ script-non-module.js
สร้างโปรเจกต์ Supabase ใหม่และตั้งค่า Database ตาม schema ที่มีใน Repo



## การใช้งานเบื้องต้น
1. เข้าสู่ระบบ / ลงทะเบียน
คลิกปุ่ม "เข้าสู่ระบบ" หรือ "ลงทะเบียน" บนเมนูด้านบน
ลงทะเบียนด้วยข้อมูลส่วนตัว หรือเข้าสู่ระบบด้วย Email และ Password

2. ดูเมนูอาหารทั้งหมด
หน้าแรกจะแสดงเมนูอาหารแบบการ์ด 3 คอลัมน์
สามารถค้นหาชื่อเมนูหรือวัตถุดิบได้จากช่องค้นหา
สามารถเรียงลำดับเมนูตามผู้สร้าง, คะแนน หรือเวลาปรุง

3. ดูรายละเอียดเมนูอาหาร
คลิกที่การ์ดเมนูอาหารเพื่อดูรายละเอียดเมนูนั้น
สามารถให้คะแนนเมนูได้ หากไม่ได้เป็นเจ้าของเมนูนั้น
เจ้าของเมนูจะเห็นปุ่ม "แก้ไขเมนูนี้"

4. สร้างเมนูอาหารใหม่
หลังจากล็อกอิน ให้คลิกที่ "สร้างเมนูอาหาร"
กรอกข้อมูลเมนูอาหารให้ครบถ้วนและบันทึก

5. แก้ไขหรือ ลบเมนูของตนเอง
ไปที่หน้าโปรไฟล์
ดูเมนูอาหารของตัวเอง
ใช้ปุ่ม "แก้ไข" หรือ "ลบ" ในแต่ละเมนู
